# Transport Management System

## 1. Purpose

A simple web-based transport management system for managing trucks, daily trips, customers, drivers, earnings, and operational records.

The primary goal is to replace notebook-and-pen based operations with one easy-to-use computerized system.

## 2. Current Business Context

The business currently operates approximately four trucks.

Daily operations include:
- Recording where each truck is going
- Recording customer/party
- Recording trip rent
- Tracking drivers and assignments
- Maintaining truck information
- Tracking EMI and maintenance information
- Tracking driver salaries and advances
- Recording return loads
- Maintaining customer contact details
- Monitoring monthly truck earnings
- Remembering important dates such as EMI and service

## 3. Product Principle

The application should be:
- Very easy to use
- Fast for daily data entry
- Useful on desktop and mobile
- Clean and professional
- Different from generic AI-generated dashboard designs
- Available in Light and Dark mode
- Designed around real transport operations rather than unnecessary analytics

## 4. V1 Goal

V1 should digitize the most frequently used notebook information without making the application complicated.

### Mandatory daily trip fields

1. Date
2. Truck
3. From
4. To
5. Customer
6. Rent

### Example

Date: 26/09/2026
Truck: GJ08AW0236
From: Abu Road
To: Ahmedabad
Customer: SK Granite
Rent: ₹850

Second example:

Date: 26/09/2026
Truck: RJ38GA3610
