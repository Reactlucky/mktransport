# Tech Stack

## Core

| Area | Technology |
|---|---|
| Framework | Next.js |
| Language | TypeScript |
| UI | React |
| Styling | Tailwind CSS |
| Database | Supabase PostgreSQL |
| Authentication | Supabase Auth |
| Storage | Supabase Storage |
| Deployment | Vercel |
| Version Control | Git / GitHub |

## Frontend Principles

- Functional React components
- TypeScript
- Reusable UI components
- Server-side capabilities where appropriate
- Responsive design
- Light/Dark mode
- Accessible forms and controls

## Database

PostgreSQL is the source of truth for business data.

Supabase provides:
- PostgreSQL
- Authentication
- Row Level Security
- Storage
- Database APIs
- Realtime capabilities when required later
